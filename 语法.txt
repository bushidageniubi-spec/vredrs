Verse 1.0 语言完整介绍（现在已经改名为Vredrs）

版本 1.0 | 发布年份 2026 | 设计哲学：诗意简洁，全栈通用

---

一、语言定位

Verse 是一门 静态与动态可选、跨平台、高性能 的通用编程语言。它融合了 C++ 的性能、Java 的跨平台能力、Python 的简洁语法，并独创了指令块、作用域前缀、pon 占位符等特性，旨在让开发者用最少的代码写出最清晰的逻辑，同时覆盖从 Web 后端到嵌入式裸机的全场景。

---

二、核心构成

1. 编译器与运行时

组件 说明
前端 词法分析、语法分析（基于缩进 + 可选花括号）、语义检查（可选类型标注）、生成中间表示（IR）
中端 独立于后端的优化层（常量折叠、内联、死代码消除）
后端 LLVM（原生）、C++ 源码生成、JVM 字节码生成、WebAssembly、Python 源码生成
运行时 协程调度器、ARC 内存管理（默认）、可插拔 GC、通道实现、异常处理栈

2. 内存管理策略

· 普通模式：自动引用计数（ARC），循环泄漏需手动 weak。
· GC 模式：编译时启用 --gc=mark-sweep，替换 ARC。
· 裸运行模式：线性类型 + 区域分配，零运行时开销，手动 unsafe 块。

3. 并发模型

· 协程：轻量级用户态线程，通过 spawn 启动，自动调度。
· 通道：send/receive 实现协程间通信，支持缓冲和 select。
· 系统线程：spawn_thread 用于 CPU 密集任务。
· 异步函数：async/await 语法糖（可选，与协程并存）。

4. 类型系统

· 动态模式：变量无需类型标注，运行时推断。
· 静态模式：显式标注类型，编译时检查。
· 泛型：支持函数、结构体、类、接口的泛型参数，单态化实现。
· 线性类型：裸模式下确保资源不被泄漏或重复释放。
· 空安全：类型后加 ? 表示可为空，配合 ?. 和 ?? 安全访问。

六、语言特色总结

· 统一指令语法：指令, 参数，所有控制流与操作形式一致。
· 指令块：/set ... /end 批量消除重复指令名，极大提升初始化效率。
· 作用域前缀块：/对象名. ... / 省去重复的对象前缀，表达嵌套数据极其清晰。
· pon 占位符：重构时无需删除已写代码，编译器自动迁移。
· 可选括号、分号、花括号：保留 Python 式缩进，同时允许 } 作为块结束符。
· 零开销抽象：泛型单态化、内联、尾调用优化，性能接近 C++。
· 多模式内存管理：默认 ARC，可切换 GC，裸模式线性类型。
· 全栈覆盖：从 Web 后端到单片机固件，一门语言通吃。

Verse 语言语法详解（第一点）

1. 输出指令 paste

语法：

```verse
paste, 表达式
paste, 表达式1; 表达式2; 表达式3
```

参数：

· 绑定符 ,：连接指令名 paste 与第一个参数。
· 参数分隔符 ;：用于分隔多个参数（当需要连续输出多个内容时）。

单词直译：

· paste —— “粘贴”。寓意将内容“粘贴”到屏幕上，比 print（打印）更形象，带有手工操作的亲切感。

小技巧：

· 如果希望输出后自动换行，使用 println（等价于 paste, "\n" 但更简洁）。
· 连续输出时，; 之间不添加额外空格。如需空格，显式写 " " 作为参数：paste, "Hello"; " "; "world" 输出 Hello world。
· 可以输出任何表达式：数字、字符串、变量、函数调用结果等。

原理解释：

· 编译器遇到 paste 指令时，会计算每个参数表达式的值，然后将其字符串表示按顺序连接，最后写入标准输出（stdout）。
· 绑定符 , 是语法层面的标记，帮助解析器区分“指令”与“函数调用”。例如 paste("hello") 会被解析为函数调用，而 paste, "hello" 才是指令。
· 参数分隔符 ; 避免与表达式内部的逗号混淆（比如列表 [1,2,3] 中的逗号）。

示例：

```verse
paste, "Hello, World!"          # 输出 Hello, World!
paste, "答案："; 42              # 输出 答案：42
paste, "PI ≈ "; 3.14159         # 输出 PI ≈ 3.14159
```
Verse 语言语法详解（第一点续）—— paste 的进阶技巧与扩展

一、连续输出的四种风格

1. 默认顺序输出（用 ; 分隔）
   ```verse
   paste, "a"; "b"; "c"    # 输出 abc
   ```
2. 带分隔符的输出（显式插入空格或标点）
   ```verse
   paste, "Hello"; ", "; "world"; "!"   # 输出 Hello, world!
   ```
3. 换行输出（使用 println 或 paste, "\n"）
   ```verse
   println, "第一行"      # 输出 第一行\n
   paste, "第二行"; "\n"   # 输出 第二行\n
   ```
4. 条件输出（结合 if 表达式）
   ```verse
   paste, "状态："; if score >= 60 then "及格" else "不及格"
   ```

---

二、倒着输出：利用列表反转

Verse 的字符串和列表都支持 .reverse() 方法：

```verse
set, msg = "Hello"
paste, msg.reverse()          # 输出 olleH
```

如果要将多个参数倒序输出，可以先将参数存入列表，反转后再用 for 循环：

```verse
set, parts = ["a", "b", "c"]
for, p, in, parts.reverse()
    paste, p; ""
/end   # 输出 cba
```

---

三、延迟输出与缓冲控制

默认 paste 是行缓冲的（遇到换行才刷新）。如需立即刷新，可使用 flush 指令：

```verse
paste, "处理中..."
flush                     # 强制输出到屏幕
# 执行耗时操作...
paste, "完成"
```

也可关闭缓冲（通过启动参数 --no-buff 或环境变量 VERSE_STDOUT_NOBUFF=1）。

---

四、输出到文件（而非屏幕）

使用 io.write 或重定向 paste 到文件：

```verse
set, f = open("log.txt", "w")
paste, "日志内容" to f   # 假设的 to 语法，实际用 f.write()
f.close()
```

标准库提供 printf 函数支持格式化输出：

```verse
printf, "名字：%s，年龄：%d\n", name, age
```

---

五、原理解释：paste 的底层实现

· 词法阶段：扫描器识别 paste 关键字，紧随其后的 , 标记为绑定符。
· 语法阶段：解析器构建 PasteNode，包含参数列表（每个参数是一个表达式树）。
· 代码生成（解释器或编译器）：
  · 解释模式：依次求值参数，调用运行时函数 verse_print 输出。
  · 编译模式（LLVM）：生成调用 printf 或系统 write 的机器码。
· 性能优化：连续多个字符串参数会合并为一次 write 调用，减少系统调用次数。

---

六、常见错误与避免技巧

错误写法 后果 正确写法
paste "hello" 缺少绑定符，编译错误 paste, "hello"
paste, "a", "b" 逗号被误解为表达式内的逗号，实际只输出 a paste, "a"; "b"
paste, 1 2 缺少 ; 分隔符 paste, 1; 2
paste, variable 但 variable 为 null 输出 null 字符串 先判断 if variable != null

七、扩展：自定义输出分隔符

通过指令块自定义全局分隔符：

```verse
/set
    OFS = ", "      # 输出字段分隔符
    ORS = "\n"      # 输出记录分隔符
/end

fn, myprint, args...
    for, i, arg, in, enumerate(args)
        paste, arg
        if i < len(args)-1 then paste, OFS
    /end
    paste, ORS
```

调用 myprint, "a"; "b"; "c" 会输出 a, b, c\n。

八、诗意编程：用 paste 书写图案

```verse
# 打印三角形
for, i, in, 1..5
    paste, "*" repeated i   # 假设有字符串重复运算符
/end
```

（注：repeated 可通过标准库实现："*".repeat(i)）

总结：paste 看似简单，但结合分隔符、缓冲控制、列表操作和自定义函数，可以实现任何输出需求。它的设计哲学是 “用一个指令完成 80% 的输出场景，剩余 20% 通过组合完成”，这正是 Verse 极简诗意的体现。
Verse 语言语法详解（第二点）

2. 变量与赋值 set

语法：

```verse
set, 变量名, 表达式
set, 变量1, 变量2, ..., 函数调用()   # 多返回值接收
变量名 = 表达式                       # 语法糖，等价于 set, 变量名, 表达式
```

单词直译：

· set —— “设置”。意为将某个值“设置”给变量，比 let 或 var 更直白，接近自然语言中的“令...为...”。

小技巧：

· 使用 /set 指令块批量初始化多个变量，避免重复写 set,：
  ```verse
  /set
      name, "Alice"
      age, 30
      city, "New York"
  /end
  ```
· 多重赋值交换变量：a, b = b, a（与 Python 一致）。
· 忽略不需要的返回值：_, rem = divmod(10, 3)。
· 变量名可以使用中文或其他 Unicode 字符（但建议用英文保持可移植性）。

原理解释：

· set 是一个指令，而不是运算符。这保持了 Verse 语法的统一性：所有操作都以指令开头。
· 变量是动态类型的（除非显式标注类型）。第一次赋值时，变量被创建并推断类型；后续可以赋不同类型的值（动态模式）。
· 多返回值接收时，set 后面跟多个变量名，逗号分隔，然后 = 或直接跟函数调用。
· 语法糖 = 在解析时会被转换为 set 指令，方便习惯 C-like 语言的程序员。

示例：

```verse
set, x, 10
y = x * 2
set, name, "Verse"
a, b = 5, 6             # a=5, b=6
q, r = divmod(10, 3)    # q=3, r=1
```
Verse 语言语法详解（第三点）

3. 输入指令 input

语法：

```verse
input, 变量, "提示字符串"
set, 变量 = input()          # 无提示版本
```

单词直译：

· input —— “输入”。直接取自计算机术语，意为从用户（或标准输入）读取数据。

小技巧：

· 若不需要提示字符串，可以省略第二个参数，此时光标直接等待输入。
· 输入的内容默认是字符串，如需数字需转换：set, age = int(input("年龄："))。
· 批量读取多个值时，可以用循环 + 列表推导：names = [input() for i in 1..3]。
· 从文件或其他流读取时，使用 io.read 而非 input。

原理解释：

· input 指令在编译后会调用底层运行时函数 read_line()，从标准输入读取一行（不含换行符），并将其作为字符串赋值给变量。
· 如果提供提示字符串，运行时先输出该提示（不换行），再等待输入。
· input 与 paste 是对偶的——一个从外往里收，一个从里往外吐。

示例：

```verse
input, name, "你叫什么名字？"
println, "你好，"; name

set, age = input("年龄：")
set, age_num = int(age)
println, "明年你"; age_num + 1; "岁"
```
Verse 语言语法详解（第四点）

4. 条件分支 if / elif / else

语法：

```verse
if, 条件
    指令...
elif, 条件
    指令...
else
    指令...
/end
```

单词直译：

· if —— “如果”。与其他语言相同，表示条件判断。
· elif —— “否则如果”。是 else if 的缩写，更紧凑。
· else —— “否则”。
· /end —— 块结束标记（也可用 }）。

小技巧：

· 单行条件可写为：if, x > 0 then paste, "正数"（无需换行和 /end）。
· 条件不需要括号，直接写表达式：if, x > 0 and y < 10。
· /if 指令块可省去重复的 if, 和 elif,：
  ```verse
  /if
      x > 0; println, "正数"
      x < 0; println, "负数"
      else; println, "零"
  /end
  ```
· 条件表达式可以是任何返回布尔值的表达式（比较、逻辑运算、函数调用等）。

原理解释：

· 解析器将 if 条件后的缩进块视为执行体。/end 显式标记块结束（缩进隐式也可，但推荐写 /end 增强可读性）。
· 条件表达式短路求值：and 和 or 从左到右，一旦确定结果便停止计算。
· 可选的 then 关键字允许单行写法，编译器会将其转换为标准的多行块。

示例：

```verse
if, score >= 90
    println, "A"
elif, score >= 60
    println, "B"
else
    println, "C"
/end

# 单行
if, age >= 18 then println, "成年"
```

5. 循环 while 和 for

语法：

```verse
while, 条件
    指令...
/end

for, 变量, in, 列表或区间
    指令...
/end

for, 变量, from, 起始, to, 结束
    指令...
/end
```

单词直译：

· while —— “当...时”。条件为真时重复执行。
· for —— “对于...”。遍历集合或范围。
· in —— “在...里面”。表示迭代的元素来源。
· from / to —— “从...到...”。定义整数范围（不含结束值）。

小技巧：

· 区间字面量 1..5 表示 1,2,3,4；1...5 表示 1,2,3,4,5。
· break 跳出当前循环，continue 跳过本次迭代。
· 循环可以带 else 子句：当循环正常结束（未触发 break）时执行 else 块。
· 使用 enumerate 获取索引和值：for, i, val, in, enumerate(list)。
· 无限循环：while, true 或 loop（loop 是 while, true 的语法糖）。

原理解释：

· for 循环的 in 后面可以是任何可迭代对象（列表、区间、字符串、通道等）。
· 编译器会将 for 展开为 while 循环加迭代器操作，或者直接生成底层循环指令。
· break 和 continue 会跳转到循环体外的适当位置，编译器会插入跳转指令。

示例：

```verse
# while 循环
set, i = 0
while, i < 5
    println, i
    i += 1
/end

# for 遍历列表
for, fruit, in, ["apple", "banana", "cherry"]
    println, fruit
/end

# for 区间
for, i, in, 1..5
    println, i   # 1 2 3 4
/end

# 带索引
for, idx, val, in, enumerate([10,20,30])
    println, idx; ": "; val
/end
```

6. 函数定义 fn

语法：

```verse
fn, 函数名(参数1, 参数2, ...)
    指令...
    return, 表达式
/end

# 简写单行
fn, add(a,b); return, a+b
```

单词直译：

· fn —— “函数”（function 的缩写）。比 def 或 function 更短。
· return —— “返回”。将值返回给调用者。

小技巧：

· 参数可以有默认值：fn, greet(name, greeting="Hello")。
· 可变参数：fn, sum(args...)，args 是一个列表。
· 多返回值：return, a, b，调用方用 x, y = f() 接收。
· 匿名函数（lambda）：set, add = fn(x,y) x+y，可直接调用 add(3,4)。
· 使用 /fn 指令块批量定义多个函数：
  ```verse
  /fn
      add(a,b); return, a+b
      sub(a,b); return, a-b
  /end
  ```

原理解释：

· 函数是“第一类公民”，可以赋值给变量、作为参数传递、作为返回值。
· 参数括号内的逗号是表达式的一部分，不与绑定符 , 冲突。
· 函数体内最后一个表达式的值会自动成为返回值（如果省略 return）。但建议显式 return 增强可读性。
· 支持闭包：内部函数可以捕获外部变量。

示例：

```verse
fn, greet(name)
    println, "Hello {name}"

fn, add(a, b)
    return, a + b

fn, swap(a, b)
    return, b, a

set, x, y = swap(10, 20)   # x=20, y=10

# 匿名函数
set, square = fn(x) x*x
println, square(5)   # 25
```

7. 结构体 struct 和类 class

语法：

```verse
struct, 名称
    字段1
    字段2
/end

class, 名称
    private, 字段
    public, 字段
    fn, new(参数...)
        self.字段 = 值
    /end
    fn, 方法(self, ...)
        ...
    /end
/end
```

单词直译：

· struct —— “结构体”（structure）。值类型，栈分配。
· class —— “类”。引用类型，堆分配，支持继承。
· private / public —— “私有” / “公有”。访问修饰符。
· new —— “新建”。构造函数名称（固定）。
· self —— “自身”。类似 Python 的 self 或 C++/Java 的 this。

小技巧：

· 结构体自动生成构造函数：Point(3,4)。
· 使用 /struct 或 /class 指令块定义多个类型。
· 结构体可以定义方法（与 struct 分开的 fn，第一个参数为 self）。
· 类支持单继承：class, Dog, extends, Animal。
· 接口定义：interface, Drawable; fn, draw(self); /end，类用 implements 实现。

原理解释：

· 结构体是值类型，赋值时复制整个内容；类是引用类型，赋值只复制引用。
· 类的构造函数 new 必须显式定义，编译器不会自动生成无参构造函数。
· self 是约定的第一个参数名，在方法内可以访问实例字段。
· 结构体和类都可以使用点号访问字段：point.x。

示例：

```verse
struct, Point
    x, y

set, p = Point(10, 20)
println, p.x    # 10

class, Animal
    private, name
    fn, new(name)
        self.name = name
    fn, speak()
        return, "..."
/end

class, Dog, extends, Animal
    fn, speak()
        return, "Woof"
/end

set, d = Dog("Buddy")
println, d.speak()   # Woof
```

8. 错误处理 try / catch / finally 与 defer

语法：

```verse
try
    指令...
catch, 错误变量
    指令...
finally
    指令...
/end

defer, 指令
```

单词直译：

· try —— “尝试”。执行可能出错的代码。
· catch —— “捕获”。处理错误。
· finally —— “最终”。无论是否出错都执行。
· defer —— “推迟”。延迟到当前作用域结束时执行。

小技巧：

· catch 块可省略，finally 块也可省略，但两者至少有一个。
· ? 运算符传播错误：data = read("file") ?，若出错则当前函数返回错误。
· defer 用于资源清理（如关闭文件、解锁互斥量），多个 defer 按后进先出顺序执行。
· 自定义错误：throw, "错误信息"。
· assert 断言：assert, x > 0, "x must be positive"（失败时抛出断言错误）。

原理解释：

· try 块内发生的异常会被运行时捕获，然后跳转到匹配的 catch 块。
· ? 运算符是语法糖，展开为 if (err) return err 模式。
· defer 在编译器级别实现：在作用域出口处插入对 defer 指令的调用。
· 异常的开销在非错误路径很小，但裸运行模式可禁用异常（改用 Result）。

示例：

```verse
try
    data = read("config.json")
    config = json.parse(data)
catch, err
    println, "加载配置失败：{err}"
    config = default_config()
finally
    println, "初始化完成"
/end

# 使用 defer
f = open("data.txt")
defer, f.close()
data = f.read()
# f 在此处自动关闭，即使 read 出错

# 使用 ? 传播
fn, load_config()
    data = read("config.json") ?
    return, json.parse(data) ?
```

9. 列表与数组

语法：

```verse
set, lst = [1, 2, 3]                # 字面量
set, empty = []                     # 空列表
set, repeated = [0] * 5             # [0,0,0,0,0]
lst.append(4)                       # 追加
lst.insert(0, 0)                    # 插入
lst.remove(2)                       # 删除第一个值为2的元素
set, val = lst.pop()                # 弹出末尾
set, val = lst.pop(0)               # 弹出指定位置
set, sub = lst[1:3]                 # 切片
lst[0] = 100                        # 修改
set, len = lst.len()                # 长度
```

单词直译：

· list —— “列表”。有序、可变的序列。
· append —— “追加”。在尾部添加元素。
· pop —— “弹出”。移除并返回元素。

小技巧：

· 列表推导式：squares = [x*x for x in 1..10]。
· 列表支持 + 拼接：[1,2] + [3,4] → [1,2,3,4]。
· 列表支持 in 检查：if 3 in lst。
· 使用 enumerate 获取索引和值：for i, v in enumerate(lst)。
· 列表可以用作栈（append/pop）或队列（pop(0) 慢，建议用 collections.deque）。

原理解释：

· 列表是动态数组，容量自动增长。元素存储在连续内存中，索引访问 O(1)。
· 切片返回新列表（浅拷贝）。
· 列表元素类型可以混合（动态模式下），但静态模式会推导为共同基类型。

示例：

```verse
set, nums = [1, 2, 3]

set, first = nums.pop(0)   # first=1, nums=[2,3,4]
set, sub = nums[0:2]    # [2,3]
for, i, v, in, enumerate(nums)
    println, "{i}: {v}"
/end
```

10. 字典（映射）

语法：

```verse
set, d = {"name": "Alice", "age": 30}
set, empty = {}
d["name"] = "Bob"               # 修改
set, val = d["age"]             # 访问，若键不存在则抛出异常
set, val = d.get("city", "NY")  # 安全访问，提供默认值
d.delete("age")                 # 删除键
set, has = d.has_key("name")    # 检查键是否存在
set, keys = d.keys()            # 获取所有键（列表）
set, values = d.values()        # 获取所有值
set, items = d.items()          # 获取键值对列表
```

单词直译：

· dict / dictionary —— “字典”。键值对映射。
· get —— “获取”。安全取值。
· has_key —— “有键”。判断键是否存在。

小技巧：

· 字典推导式：squares = {x: x*x for x in 1..5}。
· 合并字典：d1.update(d2) 或 d3 = {**d1, **d2}（展开语法）。
· 遍历字典：for key, val in d.items()。
· 使用 /set 块批量初始化字典字段：
  ```verse
  /set
      config.host, "localhost"
      config.port, 8080
  /end
  ```
· 字典的键可以是任何可哈希类型（数字、字符串、元组等）。

原理解释：

· 字典使用哈希表实现，平均 O(1) 查找。
· 键必须不可变（字符串、数字、元组）才能哈希；列表不能作为键。
· get 方法在键不存在时返回默认值而不抛异常。
· items() 返回的列表元素是 (key, value) 元组。

示例：

```verse
set, person = {"name": "Alice", "age": 30}
person["city"] = "New York"
println, person.get("name", "Unknown")
if, person.has_key("age")
    println, "年龄：{person["age"]}"
/end
for, k, v, in, person.items()
    println, "{k}: {v}"
/end
```

12. 集合（Set）

语法：

```verse
set, s = {1, 2, 3}            # 字面量（与字典区别：无冒号）

s.add(4)                      # 添加
s.remove(2)                   # 删除（不存在则错误）
```

· add / remove —— “添加” / “移除”。

· 集合推导式：evens = {x for x in range(10) if x%2==0}。

```verse
set, a = {1, 2, 3}

    println, "3 is in a"
/end
```

13. 通道（Channel）

语法：

```verse
set, ch = channel(类型, 容量)   # 创建通道
send(ch, 值)                   # 发送
set, 值 = receive(ch)          # 接收
close(ch)                      # 关闭通道
for, val, in, ch               # 循环接收直到关闭
```

单词直译：

· channel —— “通道”。协程间通信的管道。
· send —— “发送”。
· receive —— “接收”。
· close —— “关闭”。

小技巧：

· 无缓冲通道（容量=0）要求发送和接收同时就绪，否则阻塞。
· 有缓冲通道在缓冲区满前发送不阻塞，空时接收阻塞。
· select 语句多路复用多个通道操作：
  ```verse
  select
      case, receive(ch1), val; println, val
      case, send(ch2, 42); println, "sent"
      else; println, "no op"
  /end
  ```
· 使用 range 遍历通道会自动处理关闭。

原理解释：

· 通道是协程安全的，多个协程可同时读写。
· 底层实现包含互斥锁和等待队列，发送/接收时会挂起协程。
· 关闭通道后，后续发送会触发 panic；接收会返回类型零值和一个布尔标志（val, ok = receive(ch)）。
· 无缓冲通道本质上是一种同步原语（握手）。

示例：

```verse
set, ch = channel(int, 0)
spawn, fn()
    send(ch, 42)
/end
set, ans = receive(ch)   # 42

# 带缓冲
set, ch2 = channel(str, 2)
send(ch2, "a")
send(ch2, "b")
println, receive(ch2)    # a

# select
select
    case, receive(ch), v
        println, "got {v}"
    case, send(ch, 100)
        println, "sent"
    else
        println, "nothing ready"
/end
```

14. 协程（Coroutine）

语法：

```verse
spawn, 函数调用               # 启动协程
set, handle = coro(函数, 参数) # 创建协程句柄
resume(handle, 值...)         # 恢复协程，可传值
yield(值)                     # 协程内挂起并返回值
```

单词直译：

· spawn —— “产生”。启动新协程。
· coro —— “协程”（coroutine 缩写）。
· resume —— “恢复”。
· yield —— “让出”。主动挂起。

小技巧：

· spawn 启动的协程会自动调度，无需手动 resume。
· 使用 coro 创建可恢复协程，适合生成器模式。
· 协程间通信首选通道，yield 用于更精细的控制。
· 协程内发生异常会传播到 resume 调用处。

原理解释：

· 协程是用户态轻量线程，由 Verse 运行时调度，而非操作系统。
· 每个协程拥有独立的栈，初始栈大小可配置（如 8KB），动态增长。
· 协程挂起时保存寄存器状态，恢复时还原。
· spawn 创建的协程与当前协程并发执行；coro 创建的协程处于暂停状态，需显式 resume。

示例：

```verse
# 生成器
fn, counter(start)
    set, i = start
    while, true
        yield, i
        i += 1
    /end
/end

set, gen = coro(counter, 10)
println, resume(gen)   # 10
println, resume(gen)   # 11

# 并发
spawn, fn()
    for i in 1..5
        println, "协程A: {i}"
    /end
/end
spawn, fn()
    for i in 1..5
        println, "协程B: {i}"
    /end
/end
```

15. 模式匹配（Pattern Matching）

语法：

```verse
match, 表达式
    case, 模式1 [if 条件]
        指令...
    case, 模式2
```

单词直译：

· match —— “匹配”。

· 列表模式：[first, second] 匹配两个元素的列表。

18. 模块与导入

语法：

```verse
import, "模块名"                    # 导入整个模块
import, "模块名", as, 别名           # 导入并重命名
import, "模块名", 符号1, 符号2       # 仅导入指定符号
export, 符号1, 符号2                # 当前模块导出符号（默认导出所有顶层定义）
```

单词直译：

· import —— “导入”。引入其他模块的功能。
· export —— “导出”。公开当前模块中的定义。
· as —— “作为”。指定别名。

小技巧：

· 标准库无需路径，直接写模块名：import, "math"。
· 本地模块使用相对路径：import, "./utils" 或 import, "utils"（按 VERSE_PATH 搜索）。
· 使用 /import 指令块批量导入：
  ```verse
  /import
      "math", as, m
      "json"
      "os", get_env, exit
  /end
  ```
· 循环导入检测：编译器会报告模块间的循环引用。
· 模块默认是私有的，只有通过 export 公开的符号才能被其他模块访问。

原理解释：

· 每个 .verse 文件是一个模块，模块名默认是文件名（不含扩展名）。
· 导入时会编译目标模块，并缓存其符号表。
· export 可以出现在文件任意位置（但通常集中在开头或结尾）。
· 模块加载顺序由导入图决定，无循环依赖时采用拓扑排序。

示例：

```verse
# file: math_utils.verse
fn, add(a,b); return, a+b
fn, sub(a,b); return, a-b
export, add
```

19. 文件操作

语法：

```verse
set, content = read("路径")              # 读取整个文件（字符串）
write("路径", content)                  # 覆盖写入
append("路径", content)                 # 追加写入
set, file = open("路径", "模式")         # 打开文件，返回文件对象
file.read(n)                           # 读取 n 字节
file.write(data)                       # 写入数据
file.close()                           # 关闭文件
```

单词直译：

· read / write —— “读取” / “写入”。
· open —— “打开”。
· append —— “追加”。
· close —— “关闭”。

小技巧：

· 使用 defer 确保文件关闭：f = open("data.txt"); defer, f.close()。
· 按行读取：for line in f.lines()。
· 文件不存在时 read 返回 null 或抛出异常（取决于安全设置）。
· 常用模式："r" 只读，"w" 写入（覆盖），"a" 追加，"r+" 读写。
· 使用 /set 块一次打开多个文件。

原理解释：

· 文件操作底层调用操作系统的文件 API（POSIX 或 Windows API）。
· read 和 write 可能因 EOF 或错误返回 null，建议配合 ? 传播。
· 文件对象实现了 __drop__ 方法，离开作用域自动关闭（如果未显式关闭）。
· 缓冲由标准库管理，也可通过 file.flush() 强制刷新。

示例：

```verse
# 读取配置文件
set, data = read("config.json") ?
set, config = json.parse(data)

# 写入日志
set, f = open("log.txt", "a")
defer, f.close()
f.write("log entry\n")

# 按行处理
set, f2 = open("data.txt", "r")
for line in f2.lines()
    println, line
/end
```

20. 同步原语（互斥锁、等待组）

语法：

```verse
set, m = sync.mutex()          # 创建互斥锁
sync.lock(m)                   # 加锁
sync.unlock(m)                 # 解锁

set, wg = sync.waitgroup()     # 创建等待组
sync.add(wg, 1)                # 增加计数器
sync.done(wg)                  # 计数器减一
sync.wait(wg)                  # 阻塞直到计数器为零
```

单词直译：

· mutex —— “互斥”（mutual exclusion）。
· lock / unlock —— “锁” / “解锁”。
· waitgroup —— “等待组”。
· add / done / wait —— “增加” / “完成” / “等待”。

小技巧：

· 使用 defer sync.unlock(m) 防止忘记解锁。
· 互斥锁不可复制，只能通过指针传递。
· 等待组常用于等待多个协程完成。
· 原子操作：sync.atomic.add(&x, 1) 等。

原理解释：

· 互斥锁基于操作系统的原语（futex 或临界区），支持线程和协程。
· 等待组内部维护计数器，wait 在计数器不为零时让出协程/线程。
· 所有同步原语都可在协程和线程间安全使用。

示例：

```verse
set, counter = 0
set, m = sync.mutex()

for i in 1..100
    spawn, fn()
        sync.lock(m)
        counter += 1
        sync.unlock(m)
    /end
/end

sync.wait(wg)   # 等待所有协程结束
println, counter   # 100
```

21. 测试与基准测试

语法：

```verse
test, "测试描述"
    指令...
    assert, 条件, "失败消息"
/end

bench, "基准描述"
    指令...
/end
```

单词直译：

· test —— “测试”。
· assert —— “断言”。
· bench —— “基准”。

小技巧：

· 测试函数以 test 指令块编写，运行 verse test 自动执行。
· assert 失败时打印消息并标记测试失败，但继续执行后续测试（除非 -stop）。
· 基准测试运行 verse bench，会重复执行多次统计时间。
· 可以使用 /test 和 /bench 指令块批量定义。
· 测试文件命名惯例：*_test.verse。

```verse
/end
```

22. 注解（属性）

```verse
@注解名(参数1=值1, 参数2=值2)
```

23. 管道操作符 |>

语法：

```verse
表达式 |> 函数              # 等价于 函数(表达式)
表达式 |> 函数(其他参数)    # 等价于 函数(表达式, 其他参数)
表达式 |> 函数1 |> 函数2    # 链式调用
```

单词直译：

· |> —— “管道”。将左侧表达式的值传递给右侧函数。

小技巧：

· 管道可避免深层嵌套：sqrt(abs(x-5)) 写成 x-5 |> abs |> sqrt。
· 多参数时，管道值作为第一个参数传入："hello" |> string.contains("ell") 等价于 string.contains("hello", "ell")。
· 与匿名函数结合使用：[1,2,3] |> map(_, fn(x) x*x)。
· 管道优先级最低，因此 a |> f + b 被解析为 (a |> f) + b，注意加括号。

原理解释：

· 管道是语法糖，编译时重写为函数调用形式。
· 支持任意表达式作为右操作数，只要它是可调用的（函数、闭包、操作符）。
· 链式管道从左到右依次求值，每个步骤的结果传递给下一步。

示例：

```verse
# 计算平方和
set, sum = [1,2,3] |> map(_, fn(x) x*x) |> sum

# 读取文件并解析 JSON
set, data = read("config.json") |> json.parse

# 条件管道
set, result = input() |> trim |> if _ == "" then "default" else _
```

24. 可选链 ?. 和空值合并 ??

语法：

```verse
对象?.属性                # 若对象为 null，返回 null；否则访问属性
对象?.方法()              # 安全调用
表达式 ?? 默认值          # 若表达式为 null，返回默认值
```

单词直译：

· ?. —— “可选链”（optional chaining）。
· ?? —— “空值合并”（nullish coalescing）。

小技巧：

· 链式使用：user?.profile?.name ?? "匿名"。
· ?. 也可用于数组索引：arr?[i]。
· ?? 只在值为 null 时触发，false 或 0 不会触发。
· 与 ?. 配合使用避免冗长的 if x != null 判断。

原理解释：

· ?. 和 ?? 是短路运算符，不会计算后续表达式如果已经短路。
· 编译时展开为条件判断或使用特定运行时函数。
· ?? 优先级较低，通常需要括号明确结合顺序。

示例：

```verse
set, name = user?.profile?.name ?? "访客"
set, len = text?.len() ?? 0
set, first = arr?[0] ?? -1
```

28. 操作符重载（有限）

语法：

```verse
struct, Vector
    x, y
    fn, __add__(self, other)
        return, Vector(self.x + other.x, self.y + other.y)
    /end
/end
```

单词直译：

· __add__ —— “加法”。双下划线表示特殊方法。

小技巧：

· 可重载的运算符：+ - * / % == < <= > >= []（索引）。
· 重载 [] 可实现类似容器的行为：__getitem__ 和 __setitem__。
· 比较运算符重载需成对实现（如重载 == 后自动支持 !=）。
· 重载函数必须是成员函数，接受 self 和 other。

原理解释：

· 编译器遇到 a + b 时会尝试调用 a.__add__(b)。
· 如果左操作数没有定义 __add__，尝试右操作数的 __radd__。
· 内置类型（如整数）的操作符不可重载。

示例：

```verse
struct, Vector
    x, y
    fn, __add__(self, other)
        return, Vector(self.x + other.x, self.y + other.y)
    fn, __mul__(self, scalar: int)
        return, Vector(self.x * scalar, self.y * scalar)
/end

set, v1 = Vector(1,2)
set, v2 = Vector(3,4)
set, v3 = v1 + v2   # Vector(4,6)
set, v4 = v1 * 2    # Vector(2,4)
```

29. 内联汇编（裸运行模式）

语法：

```verse
unsafe
    asm {
        "mov eax, 1"
        "int 0x80"
    }
/end
```

单词直译：

· asm —— “汇编”（assembly）。
· unsafe —— “不安全”。

小技巧：

· 仅在裸运行模式下可用，普通模式禁用。
· 支持输入输出操作数约束（类似 GCC 内联汇编）。
· 语法根据目标架构（x86_64, ARM, RISC-V）不同。
· 内联汇编块中可引用 Verse 变量，需指定约束。

原理解释：

· 编译器将汇编模板嵌入生成的机器码，不进行语义检查。
· 程序员负责寄存器分配和内存一致性。
· 内联汇编与 unsafe 块配合使用，表明可能出现未定义行为。

示例：

```verse
# x86_64 下执行系统调用 exit(0)
unsafe
    asm {
        "mov $60, %rax"    # syscall number 60 (exit)
        "xor %rdi, %rdi"   # status 0
        "syscall"
    }
/end
```

30. 编译时执行（constexpr）

语法：

```verse
constexpr, 变量名 = 表达式
constexpr fn, 函数名(参数...)
    ...
/end
```

单词直译：

· constexpr —— “常量表达式”（constant expression）。

小技巧：

· constexpr 变量必须在编译期可求值（字面量、常量、纯函数）。
· constexpr 函数可以在编译期调用，也可在运行时调用。
· 常用于生成查找表、静态配置、类型计算。
· 编译器会在编译期计算并直接嵌入结果。

· constexpr 函数可以递归，但深度有限。


31. 范围（Range）

语法：

```verse
start..end               # 包含 start，不包含 end（半开区间）
start...end              # 包含 start 和 end（闭区间）
start..                  # 从 start 到无穷（惰性）
..end                    # 从负无穷到 end
```

单词直译：

· .. —— 双点，表示范围。
· ... —— 三点，闭区间范围。

小技巧：

· 范围常用于 for 循环：for i in 1..10。
· 范围可以存储在变量中：set, r = 1..5。
· 支持步长（通过 step 方法）：1..10 step 2。
· 范围是惰性的，不会立即生成所有元素。
· 可用于字符串切片："hello"[1..4] 取 "ell"。

原理解释：

· 范围对象实现了迭代器接口，在 for 循环中逐个生成值。
· 内存占用恒定（只存储 start、end、step）。
· 闭区间 ... 在编译时转换为 start..end+1。

示例：

```verse
for i in 1..5
    println, i      # 1,2,3,4
/end
for i in 1...5
    println, i      # 1,2,3,4,5
/end
set, r = 10..20
for i in r step 2
    println, i      # 10,12,14,16,18
/end
```
Verse 语言语法详解（第十点：剩余全部特性）

32. 切片（Slice）

语法：

```verse
序列[起始:结束:步长]      # 起始、结束可省略，步长可选
```

单词直译：

· slice —— “切片”。提取序列的子集。

小技巧：

· 支持负索引：arr[-2:] 最后两个元素。
· 省略起始：arr[:5] 前5个；省略结束：arr[5:] 从索引5到末尾。
· 步长为负可逆序：arr[::-1]。
· 字符串切片返回字符串，列表切片返回新列表。

原理解释：

· 切片不复制数据（对列表），只创建引用视图（不可变序列）。字符串切片因不可变也视为视图。
· 编译器在切片操作时生成边界检查代码（可在 unsafe 块中禁用）。

示例：

```verse
set, arr = [0,1,2,3,4]
set, sub = arr[1:4]      # [1,2,3]
set, rev = arr[::-1]     # [4,3,2,1,0]
set, last = arr[-2:]     # [3,4]
```

35. 断言

语法：

```verse
assert, 条件, "可选失败消息"
```

单词直译：

· assert —— “断言”。

小技巧：

· 条件为假时抛出 AssertionError。

46. 占位符 pon（Preparation Mark）

语法：

```verse
pon; 赋值语句                # 将本应写对象前缀的地方用 pon 占位
/对象名.                     # 定义作用域块，表示 pon 将被替换为该对象名
    # 空的或有内容的作用域块
/
```

单词直译：

· pon —— “准备”（preparation）。占位符，表示此处应有一个对象名或指令名，但暂时用 pon 代替。

小技巧：

· 不删除已写代码：当你已经写了一大段平铺的 alan.name, ... 后，想把它们放入 /alan. 块，只需批量替换 alan. 为 pon;（保留逗号），然后在文件后面加一个 /alan. 空块，编译器会自动将 pon 行移入块内并替换 alan。
· 也适用于指令名：例如重复写了很多 set, x, 10，可以批量替换 set, 为 pon;，然后加一个 /set 空块，自动转换。
· pon 不会被编译到最终代码，只是编译器的重构辅助标记。
· pon 只能出现在填充型指令块（如 /set）的内部。

原理解释：

· 编译器在解析时收集所有 pon; 行，并在当前模块中寻找后面定义的匹配作用域块（/对象名. 或 /指令名）。
· 匹配规则：最近的后定义且未使用的块。找到后，将 pon 替换为块标识符，并将整行移动到块内部（保持相对顺序）。
· 移动后原来的 pon 行被删除，块内生成对应的赋值语句。
· 如果找不到匹配块，编译错误。如果多个 pon 匹配同一个块，全部移入。

示例：

原始平铺代码：

```verse
/set
    alan.name, "Alan"
    alan.age, 30
    alan.city, "New York"
/end
```

程序员决定改用作用域块，但不想删除已有行。批量替换 alan. → pon;：

```verse
/set
    pon; name, "Alan"
    pon; age, 30
    pon; city, "New York"
/end
```

然后在文件末尾添加一个空的作用域块：

```verse
/set
    /alan.
        # 空块
    /
/end
```

编译器自动转换后等价于：

```verse
/set
    /alan.
        name, "Alan"
        age, 30
        city, "New York"
    /
/end
```

注意事项：

· pon 仅作为开发辅助，生产代码中不应出现（可配置编译器拒绝 pon 或当作普通标识符）。
· pon 不会影响运行时性能，因为它在编译期已被消除。
· 过度使用 pon 会降低代码可读性，建议仅用于重构临时阶段。

1. 一致性：所有模块遵循统一的命名、错误处理和文档风格。

5. 可扩展：用户可通过协议（接口）扩展标准库行为。

总结

Verse 标准库覆盖了从基础 I/O、网络、并发、加密、图像、音频、硬件控制到嵌入式裸机、插件系统等广泛领域。各模块遵循统一的设计风格，支持跨平台，性能优先。用户可根据项目需要选择性导入，保持最终可执行文件精简。

以上是 Verse 官方标准库的完整架构。后续将根据社区贡献和实际需求逐步实现这些模块，并提供详尽的 API 文档。
官方单独模块（非核心标准库，由官方维护）

除了内置的标准库（std/）之外，Verse 官方还维护一系列单独模块，它们不是默认随语言发行版一起安装，而是需要通过 vpm 包管理器单独下载。这些模块提供了更专业、更大型或与外部系统集成的功能。

补充：裸运行模式与底层特性（第53-60点）

以下特性主要面向 裸运行模式（--raw 编译标志），用于嵌入式、操作系统内核、实时系统等场景。

---

53. 裸运行模式概述

启用方式：verse build --raw --target=arm-none-eabi -o firmware.bin

效果：

· 移除运行时依赖（协程调度器、GC、反射、类型信息）
· 禁用标准库中需要 OS 的部分（如文件系统、网络、线程）
· 线性类型强制检查资源安全
· 允许内联汇编和中断处理

可用标准库子集：

· core（部分：len, str 转换, panic 等）
· math
· machine（硬件访问）
· sync/atomic
· unsafe

---

54. 中断处理

语法：

```verse
@interrupt
fn, irq_handler()
    # 中断服务例程
/end
```

单词直译：

· @interrupt —— “中断”注解。

小技巧：

· 中断函数不能有参数和返回值。
· 编译器自动保存/恢复被中断的寄存器。
· 可在中断内发送信号或设置标志，避免复杂操作。

原理解释：

· @interrupt 函数被编译为中断向量表中的入口地址。
· 函数末尾使用 iret 或 eret 指令返回。

---

55. 链接脚本与内存布局

语法：通过 --link-script 指定自定义链接脚本，或在代码中使用注解：

```verse
@section(".text.boot")
fn, _start()
    # 引导代码
/end

@addr(0x20000000)
set, shared_buffer, [u8; 4096]
```

单词直译：

· @section —— “节”。
· @addr —— “地址”。

小技巧：

· 裸运行模式默认链接脚本将代码放在 0x8000，数据放在 0x10000。
· 自定义脚本可精确控制内存映射（如 MMIO 外设寄存器）。

---

56. 内存屏障与栅栏

语法：

```verse
unsafe
    asm { "dmb" }      # 数据内存屏障
    asm { "dsb" }      # 数据同步屏障
    asm { "isb" }      # 指令同步屏障
/end
```

单词直译：

· dmb / dsb / isb —— ARM 内存屏障指令。

小技巧：

· 用于多核同步、DMA 操作、设备寄存器访问。
· x86 可使用 mfence, lfence, sfence。

---

57. 位操作与内存映射 I/O

语法：

```verse
set, ptr = 0x40020000 as ptr[u32]   # 将整数转为指针
set, val = ptr.load()               # 原子读取
ptr.store(0x1234)                   # 原子写入
ptr.store_release(0x5678)           # 释放语义写入
```

单词直译：

· as ptr[T] —— “作为指向 T 的指针”。
· load / store —— “加载” / “存储”。

小技巧：

· 用于操作外设寄存器（如 GPIO、UART）。
· 可指定内存顺序：acquire, release, relaxed。

---

58. 自旋锁与原子操作（裸机版）

```verse
import, "sync/atomic"
import, "unsafe"

set, lock = 0
fn, spin_lock()
    while !atomic.compare_and_swap(unsafe.addr(lock), 0, 1)
        # 自旋等待
    /end
/end

fn, spin_unlock()
    atomic.store(unsafe.addr(lock), 0)
/end
```

单词直译：

· spin —— “自旋”。

小技巧：

· 裸运行模式下无操作系统，只能自旋锁。
· 配合 asm { "wfe" }（ARM）或 asm { "pause" }（x86）降低功耗。

---

59. 协程禁用（裸模式）

在裸运行模式下，协程功能默认禁用（因为没有调度器）。如需轻量级任务切换，可使用 状态机 模式：

```verse
enum, TaskState
    Running, Waiting
/end

fn, task_yield()
    # 保存当前状态，跳转到调度器
/end
```

更推荐使用有限状态机 + 定时器实现协作式多任务。

---

60. 标准库裸运行版

裸模式下可用的标准库模块：

模块 可用子集
core len, str, int, float, bool, type_of, panic, assert
math 全部（纯计算）
math/big 全部（若启用分配器）
sync/atomic 全部
unsafe 全部
machine 全部（GPIO, I2C, SPI, UART, 中断）
time 仅 sleep（自旋延迟）和 ticks（CPU 周期计数）
embed 全部（文件嵌入为字节数组）

以下模块不可用：io（除非提供半主机实现）, os, net, http, json（可部分使用，但无分配器受限）, regex, crypto/tls, sql, image（除非内存充足）。

---

总结：裸运行模式将 Verse 从高级语言扩展到系统底层。通过控制内存布局、中断、原子操作和硬件映射，开发者可以用诗意的语法编写内核、驱动和实时固件。这是 Verse 区别于大多数脚本语言的核心优势之一。
## 新增语法特性（Verse 1.0 新增）

以下特性是对基础指令体系的扩展，旨在提升表达力、减少重复代码，并保持与原有语法完全兼容。

---

### 一、后缀操作符

语法：

```verse
表达式#          # 长度
表达式~          # 反转
表达式^          # 升序排序
表达式_          # 降序排序
```

单词直译：

· # —— 数量符号（Number sign），表示取长度。
· ~ —— 波浪号，象征翻转。
· ^ —— 尖号，表示上升（升序）。
· _ —— 下划线，表示下降（降序）。

小技巧：

· 适用于字符串和列表。^ 和 _ 还适用于任何可排序序列。
· 可连续使用：lst~^ 先反转再排序。
· 优先级高于所有运算符。

原理解释：

· 编译时转换为对应的标准库函数调用，零运行时开销。

示例：

```verse
set, lst = [3,1,4,1,5]
set, n = lst#            # 5
set, rev = lst~          # [5,1,4,1,3]
set, asc = lst^          # [1,1,3,4,5]
set, desc = lst_         # [5,4,3,1,1]
```

---

二、表格赋值

语法：

```verse
/set
    变量名1; 变量名2; 变量名3
    /=
        值1; 值2; 值3
        值1; 值2; 值3
        ...
    /
/end
```

单词直译：

· 表格（Table）—— 行列形式的数据。
· /= —— 赋值块开始。

小技巧：

· 第一行为变量名列表（分号分隔）。
· 后续每行是一组值，按顺序赋值。
· 适合批量初始化配置、测试数据等。
· 每个变量名只能出现一次，每行值的数量必须与变量名数量相同。

原理解释：

· 编译器将表格展开为若干条独立的赋值语句（变量 = 值）。
· 无运行时开销。

示例：

```verse
/set
    id; name; score
    /=
        1; "Alice"; 95
        2; "Bob";   87
        3; "Carol"; 92
    /
/end
```

等价于：

```verse
id=1; name="Alice"; score=95
id=2; name="Bob";   score=87
id=3; name="Carol"; score=92
```

---

三、隐式返回值

语法：

函数体内最后一个表达式的值自动作为返回值，无需 return。

```verse
fn, add(a, b)
    a + b
```

单词直译：

· 隐式（Implicit）—— 不显式写出。

小技巧：

· 仅适用于函数最后一条语句是表达式的情况。
· 仍可显式使用 return 提前返回。
· 与 return 同时存在时，显式 return 优先。

原理解释：

· 编译器在 AST 分析阶段，将最后一个表达式作为返回结果。
· 生成与显式 return 相同的中间表示。

示例：

```verse
fn, square(x)
    x * x

fn, max(a, b)
    if a > b then a else b
```

---

四、三目运算符

语法：

```verse
条件 ? 表达式1 : 表达式2
```

单词直译：

· 三目（Ternary）—— 有三个操作数。

小技巧：

· 优先级高于赋值，低于逻辑运算符。
· 表达式1和表达式2类型应兼容。
· 支持短路求值。

原理解释：

· 转换为 if 表达式，无运行时开销。

示例：

```verse
set, max = (a > b) ? a : b
set, abs = (x >= 0) ? x : -x
```

---

五、通用指令块

语法：

```verse
/指令名
    参数1
    参数2
    ...
/end
```

单词直译：

· 通用（Generic）—— 适用于任何指令。

小技巧：

· 块内每一行自动补全指令名和绑定符 ,。
· 适用于所有标准指令（set, paste, spawn, send, import 等）。
· 块内行必须顶格，不能缩进。

原理解释：

· 编译器将每行转换为 指令名, 该行内容。

示例：

```verse
/paste
    "Hello"
    "World"
/end
```

等价于：

```verse
paste, "Hello"
paste, "World"
```

---

六、模式匹配增强

6.1 守卫条件

语法：

```verse
match, 表达式
    case, 模式 if 条件
        语句...
```

小技巧：

· 先匹配模式，再检查条件，两者都满足才进入分支。
· 条件中可使用模式绑定的变量。

示例：

```verse
match, point
    case, (x, y) if x > 0 and y > 0
        paste, "第一象限"
    case, (0, 0)
        paste, "原点"
```

6.2 列表与字典解构

语法：

```verse
case, [a, b, *rest]          # 列表剩余元素
case, {"name": n, "age": a}   # 字典指定键
```

小技巧：

· 列表解构支持 *rest 捕获剩余元素。
· 字典解构只要求匹配键存在，忽略其他键。

示例：

```verse
match, data
    case, [first, second, *others]
        paste, "First: {first}, Second: {second}"
    case, {"name": n, "age": a}
        paste, "{n} is {a} years old"
```

---

七、标记 trait（Send / Sync）

语法：

```verse
marker trait Send
marker trait Sync

impl Send for MyType
```

小技巧：

· Send 表示类型可以安全地跨协程传递。
· Sync 表示类型可以安全地跨协程共享引用。
· 编译器自动为基本类型实现，用户可为自定义类型显式实现。

原理解释：

· 编译时检查，确保通道传递的元素类型实现了 Send。
· 零运行时开销。

示例：

```verse
struct, Data
    value: int

impl Send for Data   # 允许跨协程传递
```

---

八、带标签的 break / continue

语法：

```verse
'label: for i in 1..10
    break 'label
    continue 'label
```

小技巧：

· 标签以单引号 ' 开头，后跟标识符。
· break 'label 跳出标签所在的循环。
· continue 'label 跳转到标签所在循环的下一次迭代。

示例：

```verse
'outer: for i in 1..10
    for j in 1..10
        if i * j > 50
            break 'outer
```

---

以上新增特性构成了 Verse 1.0 的完整语法体系。它们均与原有指令语法兼容，可混合使用。
